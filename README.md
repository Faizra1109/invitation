### Multilingual Features (English | தமிழ் | العربية)

* **Instant Language Switcher:**
  * Segmented tabs in the header bar: **[ English ] [ தமிழ் ] [ العربية ]**
  * Instant switching without reloading the page.
  * Preserves user preference in `localStorage`.
* **Automatic Layout & Typography Adaptation:**
  * **العربية (Arabic):** Automatically applies **RTL (right-to-left)** orientation, Amiri typography, and native Arabic phrasing.
  * **தமிழ் (Tamil):** Uses Google Fonts **Noto Serif Tamil** for graceful, authentic Tamil Unicode typography.
  * **English:** Luxury serif and royal gold decorative typography.
* **Complete Content Translation:**
  * Names, academic titles, parents' honorifics, dates, time, venue, countdown labels, Quranic verses, prophetic duas, interactive guestbook placeholders, toasts, calendar events, and WhatsApp invitations are all fully translated.
